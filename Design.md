# StudyOS Design System

Design Read: calm, instrument-panel learning software for a focused student, with warm paper surfaces and ink-blue instrumentation.

- Colors: ink `#172033`, canvas `#F5F1E8`, panel `#FFFCF6`, teal `#1C7C78`, amber `#D99A2B`, muted `#687386`.
- Typography: Geist Sans for UI, Geist Mono for metrics.
- Layout: responsive two-column dashboard, 8px spacing scale, 14px radius, strong focus rings.
- Motion: short progress transitions; honor reduced-motion preferences.
