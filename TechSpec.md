# StudyOS Technical Specification

- Next.js App Router, TypeScript, Tailwind CSS, Lucide, Framer Motion.
- Supabase Auth, PostgreSQL, Storage, and pgvector.
- TypeSafe Jev is the deterministic System-1 evaluator; Gemini Flash is the generative System-2 tutor; Gemini Live powers voice.
- Server-only API keys. Browser clients use Supabase SSR and an ephemeral Live-token endpoint.
- Routes: `/api/ingest-pdf`, `/api/evaluate`, `/api/live-token`.
